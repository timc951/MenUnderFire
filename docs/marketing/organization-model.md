# Organization-Pays Model (B2B)

## Overview

In this model, organizations (churches, men's ministries) pay for the platform while individual members use it for free. This is common in the church software space.

---

## Pricing Tiers

| Tier | Price | Includes |
|------|-------|----------|
| **Starter** | $29/month | Up to 25 members, 3 groups, basic analytics |
| **Ministry** | $79/month | Up to 100 members, unlimited groups, custom branding, leader dashboard |
| **Church** | $149/month | Unlimited members, SSO, API access, priority support, dedicated onboarding |

### Comparable Pricing

- Planning Center: $0-$400/month
- Subsplash: $200+/month
- Faithlife Equip: $50-150/month
- Church Community Builder: $100+/month

---

## Why This Model Works

### Advantages

| Benefit | Description |
|---------|-------------|
| **Budget alignment** | Churches have line items for men's ministry tools |
| **Zero member friction** | Free = faster adoption within the church |
| **Sticky customers** | Organizations churn less than individuals |
| **Ministry culture fit** | "We provide this for our men" messaging |
| **Sales efficiency** | Talk to 1 pastor vs. 100 individuals |
| **Predictable revenue** | Monthly/annual contracts |

### Challenges

| Challenge | Mitigation |
|-----------|------------|
| Longer sales cycle | Offer free pilot programs |
| Committee approvals | Provide ROI documentation |
| Need admin features | Prioritize leader dashboard early |
| Seasonal buying | Plan for fall budget season |

## Features Organizations Want

### Must-Have (MVP)

| Feature | Description |
|---------|-------------|
| **Admin dashboard** | View all groups, member activity, engagement stats |
| **Leader management** | Assign/remove group leaders |
| **Bulk invites** | Email list import, shareable invite links |
| **Privacy controls** | Keep groups private to their organization |

### Nice-to-Have (Growth)

| Feature | Description |
|---------|-------------|
| **Custom branding** | Church logo, colors, welcome message |
| **Reports** | Monthly engagement reports for elders/pastors |
| **SSO integration** | Connect to church directory systems |
| **API access** | Integrate with existing church tools |

## Go-To-Market Strategy

### Phase 1: Pilot (Months 1-3)

1. Recruit 3-5 pilot churches (free or heavily discounted)
2. Work closely with them to refine admin features
3. Collect testimonials and usage data
4. Build case studies

### Phase 2: Early Sales (Months 4-6)

1. Target men's ministry networks:
   - Iron Sharpens Iron
   - Man in the Mirror
   - Church planting networks
2. Attend 1-2 men's ministry conferences
3. Create referral program (churches refer churches)

### Phase 3: Scale (Months 7-12)

1. Hire part-time church relations person
2. Build self-serve signup for smaller churches
3. Add annual billing option (2 months free)
4. Partner with denominations

## Hybrid Option

You can run both models simultaneously:

| Track | Model |
|-------|-------|
| **Public/Open** | Anyone joins free, donation-supported |
| **Organization** | Churches pay for private, branded experience |

This lets individuals discover the platform organically while churches get a premium managed experience.
